# Trend Journal

This directory stores daily trend and demand research as **agent-scoped** files:

`YYYY-MM-DD-<agent>.md`

| Agent | Filename slug | Example |
| --- | --- | --- |
| ChatGPT / Codex | `chatgpt` | `2026-07-30-chatgpt.md` |
| Claude | `claude` | `2026-07-30-claude.md` |
| Cursor | `cursor` | `2026-07-30-cursor.md` |
| Cursor / Grok workflows | `cursor` (same slug; use Cursor space) | `2026-07-30-cursor.md` |
| Gemini Spark | `gemini` | `2026-07-30-gemini.md` |

Each agent writes **only** its own file for the day. Do not edit another agent’s journal file. Never overwrite an existing agent-day file; if you must add more for the same day, append an attributed section inside your own file.

Each entry must preserve prior work in that file, attribute material changes, and separate **Verified evidence**, **Inference**, and **Assumptions**.

Opportunities may be **B2B, B2B2C, or B2C** — not B2B-only. State the motion and who pays.
